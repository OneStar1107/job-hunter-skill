# job-hunter · AI 求职教练技能

装在 AI 助手里的求职教练——用「档案优先」的方法论，帮你改简历、挖项目、练面试、管投递，直到拿到 offer。

## 这是什么

`job-hunter` 是一个 Skill（技能包），可加载到支持 Skill 机制的 AI 助手（如 WorkBuddy）中。加载后，AI 会以**求职教练**的身份工作：它先读你的求职档案，再基于档案给出每一条建议——所有建议可执行、可验证、有验收标准，拒绝"多练习""要自信"这类空话。

技能自带一份**虚构示例档案**（人物：小陈，示例方向：产品运营——可替换为任何方向），用于演示完整工作流。首次使用请运行 `档案` 命令，把示例替换成你自己的真实信息。

## 用来干什么

| 能力 | 具体做什么 |
|---|---|
| 简历打磨 | ATS 兼容审计、HR 七秒扫描模拟、逐节重写、针对 JD 的关键词缺口分析、母版简历定制策略 |
| 项目深挖 | 把项目经历提炼成简历 bullet 和面试可讲的故事（STAR），每条过 XYZ 检验和数字检验 |
| 模拟面试 | 技术问答 + 场景排障 + 行为面 + 压力面；智能追问、五维评分、面试官视角复盘、当场重答 |
| 投递辅助 | 岗位匹配度打分、JD 差距分析、定制招呼话术、投递清单；**提交前必须人工确认** |
| 数据复盘 | 投递日志、面试进度追踪、每 20 份投递触发小复盘，找瓶颈定计划 |

## 面向谁

- **应届生 / 转行者**：简历没东西写、不知道问题在哪、海投没回音
- **简历总被拒的人**：需要 HR 视角的七秒扫描审计和 ATS 关键词补齐
- **有项目不会写的人**：项目做完了，但提炼不成简历上的一条 bullet
- **需要结构化陪练的人**：面试紧张、答不全、被追问就慌
- **投递没章法的人**：海投无回音，需要匹配度打分和节奏管理

方法论是岗位无关的：改掉档案里的目标岗位和关键词库，即可服务开发、产品、运营等任何求职方向。

## 快速开始

1. 将本文件夹放入 AI 助手的 skills 目录（WorkBuddy 用户级路径：`~/.workbuddy/skills/`）
2. 对 AI 说：**`档案`** —— 按引导建立你自己的求职档案（约 5 分钟）
3. 之后随时说：

| 命令 | 同义说法 | 用途 |
|---|---|---|
| `档案` | 更新档案、我的资料 | 创建/更新求职档案 |
| `简历` | 改简历、简历批改、针对JD改简历 | 简历审计与打磨 |
| `项目` | 项目深挖、项目怎么写 | 项目经历提炼成简历 bullet + STAR 故事 |
| `面试` | 模拟面试、陪我练面试、mock | 完整模拟面试 + 评分 + 复盘 |
| `投递` | 投简历、找工作、搜岗位 | 岗位匹配打分 + 定制招呼话术 |
| `复盘` | 看看进度、每周复盘 | 投递/面试数据复盘 |

## 设计原则

1. **档案优先**——建议必须基于真实档案，矛盾时以用户最新口述为准
2. **一次只问一个问题**——按顺序推进，不一次倒出一堆问题
3. **先讲优势，再讲问题**——具体引用原文，但硬话不回避
4. **证据分级**——市场判断标置信度，不知道就说不知道
5. **不说正确的废话**——每条建议有动作、有对象、有验收标准
6. **收尾必须给下一步**——一句话命令 + 理由 + 备选
7. **投递红线**——永不自动提交投递，永不批量群发（详见 `references/apply-flow.md`）
8. **方案必配图**——需要用户做选择时，先用可视化图表呈现对比

## 目录结构

```
job-hunter-skill/
├── SKILL.md                        # 技能主文件（触发词、命令注册表、核心原则）
├── references/
│   ├── profile.md                  # 求职档案模板（含虚构示例人物小陈）
│   ├── resume-rules.md             # 简历打磨规则与审计流程
│   ├── interview-bank.md           # 面试模块：规则 + 评分体系 + 题库
│   └── apply-flow.md               # 投递辅助流程与安全红线
├── LICENSE                         # MIT
└── README.md
```

求职过程中产生的数据（投递日志、各版本简历）存放在用户本机的「求职」文件夹，不在本仓库内。

## 安全红线

- 本技能**永不自动提交任何投递**：可以搜岗位、匹配分析、生成话术、辅助填表到提交前一步；点击"发送/投递/报名"之前必须停下等用户确认
- **禁止全自动批量群发**：违反招聘平台规则会导致账号降权封号
- 浏览器辅助填写模式下，账号登录由用户本人完成
